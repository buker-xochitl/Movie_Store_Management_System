# Movie Store Management System

A Java console application that allows users to manage a movie database through searching, sorting, and file storage.

## Features

- Add and remove movies
- Search by title, actor, year, or genre
- Sort movies alphabetically
- Password-protected manager mode
- Save and load movie data from a text file

## Technologies

- Java
- Object-Oriented Programming (OOP)
- ArrayList Collections
- File I/O
- Exception Handling
